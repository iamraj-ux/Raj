Setup once, then just “k”

Recommended: spec-in-project. You paste one setup prompt a single time. It saves the rules and every stage as files in your project. After that you type short commands only, so nothing is repeated.

  1. Paste the setup prompt once. It writes 3 files and changes no app code.
  2. Type k. The assistant runs the next stage in CHECKLIST.md, reading only that stage’s section (about 100–250 tokens).
  3. Replies are capped. Diffs only, about 250 lines at most, split into PART n/m if longer, so a reply never hits the limit mid-way.
  4. Chat reset? Type resume. It re-reads the rules and checklist and carries on.

Honest note: this relies on the assistant being able to read and edit project files. If your tool can’t, paste the BUILD_RULES.md part at the start of each new chat instead.
